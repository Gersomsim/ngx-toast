Notifications & confirmations
for Angular.

ngx-notify is a lightweight Angular library that provides a simple and flexible way to display toast notifications and confirmation dialogs in your applications.

It is designed to be easy to integrate, fully typed with TypeScript, and customizable to adapt to different UI needs. The library focuses on providing a clean developer experience while keeping the API minimal and intuitive.

With ngx-notify, developers can quickly add user feedback mechanisms such as success messages, error alerts, warnings, and confirmation dialogs for critical actions.

The library is designed to work with modern Angular applications and leverages the standalone provider pattern for a simpler setup and better tree-shaking.

Toast notifications support stacked rendering, meaning multiple notifications can appear simultaneously without overlapping. Each notification is displayed in sequence within the same container.

Installation

Install via your preferred package manager.

The library includes its own styles, so no additional CSS imports are required.

Setup

Register the library once in your application config using NgxNotify.provide(). No modules needed.

This global configuration defines the default behavior for toast notifications and confirm dialogs across your application.

Basic Usage

Call NgxNotify can be used in two different ways:

  • Using the Angular services
  • Using the static facade

Both approaches are independent.

If you use the services directly, no global configuration is required.

Global Configuration

ngx-notify allows you to define global defaults for notifications and confirmation dialogs using the provider configuration.

This configuration helps maintain consistent behavior and styling across the entire application.

A recommended approach is to define a configuration file at the root of your project.
