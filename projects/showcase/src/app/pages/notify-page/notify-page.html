ngx-notify

Toast Notifications

ngx-notify provides a simple and flexible API for showing toast notifications.

You can either use quick helper methods or the advanced show() method for full customization.

Quick Notifications

The fastest way to show a notification is using the helper methods.

NgxNotify.show()

For more advanced control, you can use the show() method.

You can override the global configuration for a specific notification.

Per-call configuration

The shorthand methods accept a partial ConfigNotify as a second argument, letting you override duration, position, or animation per call.

NgxNotifyService — injectable API

For scenarios where you prefer Angular's dependency injection, NgxNotifyService exposes the same .show() method via injection. It is provided in root automatically after calling NgxNotify.provide().

Position-specific methods

Convenience methods that combine a type shorthand with an explicit position, useful when you want different notification types to appear at different corners simultaneously.

Dismiss all

Call NgxNotify.closeAll() to programmatically dismiss every visible notification at once.
