ngx-confirm

Confirmation Dialogs

ngx-confirm provides a lightweight confirmation dialog for Angular applications. It allows you to request user confirmation before executing critical actions such as deleting data, resetting settings, or submitting important changes.

The dialog is fully configurable and communicates the user action through a callback event.

Basic Usage (Static Facade)

The simplest way to open a confirmation dialog is using the NgxNotify.confirm() static method.

The callback receives an event object that describes the user interaction.

Using the Service

You can also use the NgxConfirmService directly in a component or service.

Using the service does not require configuring the global provider.

Handling the callback

The callback receives a ConfirmEvent object regardless of how the dialog was dismissed. Use event.type for precise control or the boolean flags for simple branching.

Auto-dismiss timer

When both showConfirmButton and showCancelButton are false, the dialog acts as an alert and auto-closes after timer milliseconds. Pair it with showTimerProgressBar for a visual countdown.
